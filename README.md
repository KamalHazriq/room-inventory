# room-inventory

A personal room inventory PWA. Not built yet — this repo currently holds only the build brief.

## What this is

One room, a storage trolley, labelled boxes. The app answers two questions in under five seconds on an iPhone:

1. Do I already own this, or do I need to buy it?
2. I own it, but where did I put it?

## Start building

Open this repo in Claude Code and paste [PROMPT.md](PROMPT.md) as the first message.

Planned stack: Vite + React + TypeScript, Tailwind, Firebase (Firestore + Google auth), installable PWA deployed to GitHub Pages.
